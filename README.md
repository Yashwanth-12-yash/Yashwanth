## 📂 Featured Projects

### 🛒 NexTrade: AI-Powered E-Commerce Platform
A full-stack e-commerce platform with separate **customer and admin modules**, covering cart, wishlist, and order management, plus an **AI-driven product recommendation** feature.

- **Backend:** Django + SQL models for users, products, inventory, addresses, and orders
- **Frontend:** Responsive UI in HTML, CSS, and JavaScript
- **Stack:** `Python` `Django` `SQL` `HTML` `CSS` `JavaScript`

### 🤖 TCS Chatbot: RAG-Based Generative AI Chatbot
A context-aware chatbot that answers questions **grounded in uploaded documents**, reducing hallucinations by retrieving relevant passages before generating.

- **Pipeline:** PDFs parsed with `PyPDFLoader`, chunked with `RecursiveCharacterTextSplitter`
- **Retrieval:** `all-MiniLM-L6-v2` embeddings stored in a persistent **FAISS** index
- **Generation:** OpenAI GPT orchestrated through LangChain
- **Stack:** `Python` `LangChain` `OpenAI GPT` `RAG` `Hugging Face` `FAISS`

### 🩺 Diabetes Prediction Using Machine Learning
A classification model that predicts diabetes from patient health data.

- Full workflow: EDA, feature engineering, training, and evaluation
- Benchmarked **Logistic Regression, KNN, Naive Bayes, and Random Forest**
- **Stack:** `Python` `Pandas` `NumPy` `Scikit-learn` `Matplotlib`
