### 🤖 TCS Chatbot — RAG-Based Generative AI Chatbot

**Technologies:** Python, LangChain, OpenAI GPT, RAG, Hugging Face, FAISS

A document-based chatbot that generates context-aware answers from uploaded PDF files.

#### Key features

- PDF document ingestion using `PyPDFLoader`
- Text splitting using `RecursiveCharacterTextSplitter`
- Semantic embeddings using `all-MiniLM-L6-v2`
- Vector storage and similarity search with FAISS
- Retrieval-Augmented Generation pipeline
- Context-grounded responses using OpenAI GPT
- Persistent vector-store storage

#### RAG workflow

```text
Upload PDF
   ↓
Extract document text
   ↓
Split text into chunks
   ↓
Generate embeddings
   ↓
Store embeddings in FAISS
   ↓
Retrieve relevant context
   ↓
Generate an answer with the LLM
```
